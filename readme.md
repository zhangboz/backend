# WeChat Mini-App Homework Helper Backend

This is the backend server for the Homework Help AI app. It's built with Express.js.

## Core Functions

The server provides the following main functionalities:

1.  **WeChat User Login (`/api/login`)**:
    *   Handles login requests from the WeChat Mini Program.
    *   Takes a `js_code` from the client.
    *   Exchanges it with the WeChat API for an `openid` and `session_key`.
    *   Returns the `openid` to the client.

2.  **Homework Processing (`/api/process-homework`)**:
    *   Accepts file uploads (images or PDFs) representing homework.
    *   Uses Multer for handling file uploads, storing them temporarily in the `./uploads` directory.
    *   Sends the uploaded file to the Google Gemini AI (`GoogleAI_Agent.mjs`) for understanding/analysis.
    *   Returns the AI's text-based reply.
    *   Deletes the uploaded file from `./uploads` after processing.

3.  **Markdown Export (`/api/export/:format`)**:
    *   Accepts Markdown text from the client.
    *   Converts the Markdown to the specified `format` (either `docx` or `pdf`) using Pandoc (via `fileExport.mjs`).
    *   Saves the converted file temporarily in the `./temp_exports` directory.
    *   Returns a download URL (`/api/exports/<filename>`) for the client to fetch the file.
    *   Schedules the temporary exported file for deletion after a short period (e.g., 5 minutes).

4.  **Static File Serving for Exports (`/api/exports/<filename>`)**:
    *   Statically serves files from the `./temp_exports` directory.
    *   Middleware ensures `Content-Disposition: attachment` is set to force downloads.

## Key File Structure Points

*   **`server.mjs`**: Main Express app setup, middleware, route mounting, global error handler, and server start. Initializes `uploads` and `temp_exports` directories.
*   **`routes/`**: Contains modular router files:
    *   `loginRouter.mjs`: Handles `/api/login`.
    *   `processHomeworkRouter.mjs`: Handles `/api/process-homework`, includes Multer setup.
    *   `exportRouter.mjs`: Handles `/api/export/:format`.
*   **`AI_ChatBot/GoogleAI_Agent.mjs`**: Logic for interacting with the Google Gemini API.
*   **`FileProcessor/fileExport.mjs`**: Logic for converting Markdown using Pandoc and scheduling file deletions.
*   **`uploads/`**: Temporary storage for files uploaded via `/api/process-homework`.
*   **`temp_exports/`**: Temporary storage for files generated by `/api/export`.

## Setup & Running

1.  Ensure Node.js and npm are installed.
2.  Clone the repository (if you haven't already).
3.  Install dependencies: `npm install`
4.  Create a `.env` file in the `backend` root directory with the following variables:
    ```
    PORT=5000
    WX_APP_ID=your_wechat_app_id
    WX_APP_SECRET=your_wechat_app_secret
    GEMINI_API_KEY=your_google_gemini_api_key
    # PANDOC_PATH=/optional/path/to/pandoc (if not in system PATH and fileExport.mjs needs it explicitly)
    ```
5.  Start the server: `npm start` (or `node server.mjs` if nodemon/etc. isn't configured in `package.json`)

## Important Reminders

*   **Environment Variables**: Critical for WeChat login (`WX_...`) and AI features (`GEMINI_...`).
*   **File Deletion**: Temporary files in `uploads/` and `temp_exports/` are automatically deleted.
*   **`trust proxy`**: Enabled in `server.mjs` for correct `req.protocol` when deployed behind a reverse proxy (like Render).
*   **Error Handling**: Global error handler in `server.mjs` catches unhandled errors, Multer errors, and custom file filter errors.
